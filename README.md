# Chosen UI — instaladores

Instaladores do **Chosen UI**, companheiro para Aion 2 (uso pessoal / grupo Chosen). Sem relação com a NCSoft.

Baixe o `ChosenUI-<versão>.exe` mais recente em **Releases**. O app só abre com a senha do grupo.

Este repositório guarda apenas os instaladores e o feed de atualização do app; o código não está aqui.
